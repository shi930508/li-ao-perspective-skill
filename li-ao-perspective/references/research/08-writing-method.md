# 李敖：写作方法

## 证据标记

- **[事实]**：可由作品、手稿描述、同期访问或书目核对的行为。
- **[自述]**：李敖本人对方法、动机和成绩的解释；不等于独立验证。
- **[推断]**：由多个作品与行为样本归纳的工作模型。

本页讨论“他怎样生产文字”，不替他的史实判断背书。李敖资料站保存了大量原文、序跋和节目转写，是重要的一手文本入口，但属私人整理，可能有错字或转写误差；涉及数量、日期时优先与国家图书馆、同期媒体或机构记录互证。

---

## 一、核心模型：先把世界变成资料夹，再把资料夹变成文章

李敖的写作并非从空白页开始，更接近一个长期运行的个人研究系统：

> 日常扫读与搜集 → 剪下可用单元 → 按私人问题分类 → 选出可攻击／可翻案的命题 → 调出证据组 → 以故事、反转和讽刺组织 → 手写定稿 → 转成专栏、书、节目或演讲。

这套方法的竞争优势是检索速度、材料稀缺性和个人语气；主要风险是分类系统只有本人懂、对反证的选择可能受立场影响，以及高产会压缩复核与修订。

---

## 二、选题：优先选择“已有公共说法，但仍可被证据翻案”的问题

### 可观察做法

- **[事实]** 作品长期围绕人物评价、政治神话、制度争议、禁忌题材和他本人卷入的冲突，常见系列如“研究”“真面目”“你不知道的……”及“给……难看”。国家图书馆书目和《李敖大全集》目录可核其连续性。
- **[自述]** 他把写作描述为纠正被权力、宣传或学界遮蔽的记录；在访问中强调，情绪化语言背后仍要有思想和丰富资料。
- **[推断]** 选题过滤器不是“重要即可”，而是同时满足三项：有对手、有反常识证据、有传播冲突。纯综述价值通常低于可推翻既有评价的题目。

### 常见选题入口

1. **官方说法与原始文件不一致**：以档案、旧报、照片版本或当事人文字反查。
2. **名人形象过于完整**：寻找被删掉的人、未完成的书、前后矛盾的说法。
3. **当下争议缺少历史纵深**：用外国或中国史故事建立比较。
4. **别人已批评他**：把来函、判决、报道本身纳入下一篇文章的材料。
5. **媒介出现新限制**：把限制当作文体条件；例如微博140字被他改造成短论断体。

### 可复用选题问句

- 大家都相信的版本，最早证据是什么？
- 对方自己的文件中，有没有能反证对方的话？
- 哪个细节被所有摘要省略，却会改变结论？
- 能否找到一件实物、照片或原话，让抽象判断可见？
- 这个题目除了“骂”，还能留下什么新材料？

## 三、资料准备：“大卸八块”不是速读术，而是建立检索单元

### 1. 破坏书的物理完整，换取材料的可调用性

- **[事实]** 《商业周刊》1998年进入其书房报道：他看到有用材料便剪下，分门别类放入资料夹；当时已有四千多个资料夹、六万余册藏书，并自创只有自己能读懂的分类码。
- **[自述]** 《李敖秘密书房》中，他反复强调历史研究必须掌握大量文件、文献、孤本和隐秘资料，单靠一般知识不能进行人物翻案。
- **[推断]** 他的阅读完成标准不是“读完一本书”，而是“有价值片段已进入未来题目的位置”。书是临时容器，主题资料夹才是长期资产。

### 2. 分类按“将来怎么用”，而非图书馆学科

图书馆分类回答“这是什么书”；李敖式私人分类更可能回答“将来可用来证明什么”。这解释了为什么系统难以交给助理：它把人物、指控、故事、反例和修辞用途混在个人记忆中。

**可复用字段**：

- 议题／人物
- 证据支持哪一命题
- 证据来源与日期
- 原件、影印、转述或二手报道
- 对方可能怎样反驳
- 可用于开场、核心证据、类比或笑话
- 仍待核实之处

### 3. 搜集不仅求“多”，还求难以替代

- **[事实]** 《秘密书房》节目常直接展示旧书、照片、手札和文件，并说明取得过程。
- **[事实]** 写《北京法源寺》时，他未亲临现场；同学替他拍摄七十多张照片、丈量并绘图寄台，补足空间资料。
- **[推断]** 当不能亲访时，他会把研究任务拆成可委托的观察指标：照片、尺寸、平面关系，而不是只请人写印象。这是少数可见的协作，但不等于他有常设研究团队。

## 四、从材料到论点：证据包围，不做平均分配

### 基本论证骨架

对大量评论文和节目文本的观察，可归纳出以下高频结构：

1. **先下判断**：开门给出异常、挑衅或反常识结论。
2. **让对方出场**：引用对方原话、官方版本或社会常识。
3. **放入一件硬材料**：文件、日期、照片、旧版文字、判决或统计。
4. **补一个历史故事**：把抽象问题变成人与处境。
5. **指出版本差异**：谁被删了、哪句话改了、前后说法如何冲突。
6. **扩大到制度解释**：由个案指向审查、宣传、权力或人性。
7. **以讽刺收口**：把复杂结论压成一句可记忆的反转。

### “详人所略，略人所详”

- **[自述]** 《北京法源寺》后记说明，他不准备平均叙事，而要展开别人忽略之处，对熟知桥段则少写；必要时允许人物长篇议论。
- **[推断]** 这是他跨文体的编辑原则：篇幅由论点价值分配，不由事件在传统叙事中的名气分配。
- **代价**：思想密度高，但小说人物容易成为观点载体，情节与人物自主性会受损；外部评论确实长期质疑其小说“议论多于叙事”。

### 反证与并列版本

《李敖有话说》谈唐太宗史料时，他会并列两个版本并承认无法判定何者为真；谈历史照片时则把修改前后图像并置。这说明他具备展示证据冲突的能力。但不能由此推定所有文章都同样公平地处理反证；最安全的复用方式是强制增加“最强反方证据”一步。

## 五、标题：标题先承诺冲突，不先概括目录

### 高频标题结构

根据国家图书馆书目与其作品总目录，可见几类稳定模式：

- **揭幕式**：`X的真面目`、`你不知道的X`——承诺独家证据。
- **挑战式**：`给X难看`、`X骗了你`——明确对手与动作。
- **对偶式**：`传统下的独白／独白下的传统`——翻转词序制造记忆点。
- **自我品牌式**：标题直接放入“李敖”，把作者本人变成题材。
- **系列式**：研究、续集、三集直至六集——把一次选题建设为持续档案。
- **挪用改写式**：借古书名、成语或名句，换一字或重配语境。

### 标题生产公式

> 对象 + 被遮蔽的信息／主动动作 + 读者利益或威胁

例如不要写“蒋介石史料考辨”，而会倾向“你不知道的蒋介石”或“蒋介石的真面目”。标题的优点是清楚、可传播；缺点是先建立敌我，容易让研究沦为只搜有罪证据。

**护栏**：先完成证据表，再写攻击性标题；若标题强于证据，就降级标题，而不是补写夸张结论。

## 六、引注与证据呈现：让来源成为剧情的一部分

### 可观察特征

- **[事实]** 他经常直接报出书名、作者、人物、日期与文句来源；在电视中进一步把书、文件和照片举到镜头前。
- **[推断]** 引证不仅承担学术核查，也承担表演功能：一份难得文件同时证明命题、展示收藏能力并压迫对手。
- **[事实]** 其文体横跨学术评论、杂文、节目和小说，注释规范并不一致；不能把“资料多”自动等同于现代同行评审式的完整引注。

### 李敖式证据排序

1. 对方本人的文字或机构文件
2. 同期记录、旧报、照片、书信、判决
3. 权威学者或经典文本
4. 历史故事与比较案例
5. 本人经验和判断

### 现代复用时必须补上的项目

- 页码、版本、馆藏或稳定链接
- 原始材料与转引材料分级
- 图片是否经过裁切、编辑或误标
- 同一事件的最强反方来源
- 事实结论、价值判断和讽刺句分别标注

## 七、叙事：用小故事搬运大观点

### 故事的四种用途

1. **开锁**：先讲一个人物轶事，让读者进入抽象议题。
2. **类比**：用外国政治家或中国史人物照亮台湾现实。
3. **证据拟人化**：让一封信、一张照片、一本旧书有来历和命运。
4. **自我作证**：把入狱、官司、藏书、拍卖等经历放进论证。

《世论新语》自序明确赞赏短故事“落墨不多”而有味道，反映他把轶事当作高压缩文体。其典型段落不是平铺史实，而是“故事—转折—解释—当下对象”。

### 叙事的风险

- 故事比统计更容易被记住，也更容易让个案替代总体。
- 本人经历既是证据，也是品牌资产，可能使议题最终回到“李敖如何正确”。
- 历史人物常被安排为观点代言人，需防止把后世判断写回人物内心。

## 八、讽刺：先有肉，再加辣椒

### 本人的方法说明

- **[自述]** 在长访谈中，他说情绪化语言之后必须还有思想和丰富资料，形容文章不应只有“辣椒”，还要有“肉”。
- **[自述]** 他称自己“以证据骂人”，并把语言目标概括为内容可信、措辞巧妙。
- **[自述]** 他赞成白话口语化，不回避俗语俗字。

### 可观察的讽刺装置

- **字面反转**：把对方口号按字面推到荒谬结果。
- **高低并置**：经典、外文名句和俚语、粗口在同段碰撞。
- **自夸作笑点**：先把自己夸到不可信，再借笑声取得解释空间。
- **改写名句**：保留熟悉节奏，只换关键谓语或对象。
- **假让步**：先承认对方一小点，再把它转成更重的批评。
- **命名攻击**：用固定绰号降低对方庄严感。

### 操作顺序

> 先写无讽刺版论证 → 检查每个事实 → 找到最荒谬的结构性矛盾 → 只在转折与收尾加讽刺。

如果删除笑话后文章不成立，就不是“有资料的讽刺”，而是纯表演。

## 九、草稿、修改与定稿：确定的是手写和定额，不确定的是改几遍

### 已有证据

- **[事实]** 凤凰卫视刘长乐回忆，李敖不用电脑、没有文字助理，书稿、演讲稿、札记和节目串词多由本人夜间手写。
- **[自述]** 《秘密书房》中展示不同书写工具，解释大量手写时会轮换毛笔、钢笔、圆珠笔、签字笔以改变手势、减轻负担；自称有日写数千乃至上万字的记录。
- **[事实／自述文本]** 1992年日记写“每天至少一千字用在专书”；1995年又制定1200天计划，把小说和《中国思想史》各拆成每日“定稿”至少500字。

### 证据空白

现有高质量公开资料未能稳定说明：一篇文章通常打几遍草稿、是否交编辑试读、逐句修改比例或校样流程。作品中有精密结构，不能反推他必然多轮重写。“定稿500字”至少证明他区分产出与可交付文字，但不足以虚构完整修订程序。

### 安全推断

他的重工作可能更多发生在写前：长期分类、调材料、在头脑中形成攻击路线；动笔后依靠熟练度快速推进。此为**推断**，应与“他从不改稿”这种无证据断言区分。

## 十、产量管理：把书拆成每日可结算的定稿单位

### 可见机制

- **长期项目量化**：小说20万字、《中国思想史》每册20万字，倒推400天和1200天。
- **双轨推进**：小说与思想史各有每日最低定稿量，杂文和副产品不计入核心计划。
- **媒介复用**：研究材料可先成为专栏、节目，再汇成书或系列续集。
- **身体工程**：轮换笔具与姿势，承认高产是体力劳动。
- **降低社交占用**：在《秘密书房》中，他以胡适人缘好却多部书只完成上卷为反例，表达保护深度工作时间的偏好。
- **适应长度限制**：晚年接受140字限制，将其视为新文体而非停止写作。

### 产量数字的使用边界

他在节目中自称《大全集》四十册、一千五百万字；这是本人统计，且“全集”含旧作重编、访谈与不同文体。研究方法时可用来证明规模意识，不宜当作全部独立新写字数的精确审计。

## 十一、从研究到成稿：可操作工作流

### Step 1：写一句可被证伪的主张

不是“谈谈某人”，而是“某人的公共形象遗漏了X，证据是Y”。若不能被反驳，就无法知道需要什么证据。

### Step 2：建立四格证据夹

| 格 | 内容 |
|---|---|
| A | 对方自己的原话／文件 |
| B | 同期外部记录 |
| C | 后续判决、档案或研究 |
| D | 最强反证与尚不能确定之处 |

### Step 3：先排“硬材料顺序”，后写漂亮句子

选出一件开场材料、两件核心材料、一件反证、一件结尾材料。其余进入附录，避免资料多却主线散。

### Step 4：搭七段骨架

异常结论 → 通行版本 → 核心证据 → 版本冲突 → 历史故事 → 制度解释 → 讽刺收束。

### Step 5：选择标题动作

要揭幕、挑战、纠错、反转还是续案？标题只能承诺正文已证明的事。

### Step 6：写无辣椒初稿

每段先写事实、来源和推理。事实与判断分句，无法证实处写明“不知道”。

### Step 7：只给三个位置加锋芒

开场一句、核心转折一句、结尾一句。讽刺指向权力与逻辑矛盾，避免用弱者身份作笑料。

### Step 8：定稿配额

按每日可交付字数推进，不按“今天有没有灵感”。长项目拆成400—1200天的可结算单位；每周保留一次证据复核，不用产量替代准确。

### Step 9：反李敖式校验

- 是否只搜到对自己有利的资料？
- 是否因标题太好而夸大结论？
- 故事是否被当成总体证据？
- 引用是否能回到具体版本与页码？
- 删掉自我品牌后，论证还成立吗？

---

## 十二、方法的优势与代价

| 优势 | 代价 |
|---|---|
| 私人资料库使冷门材料可快速调用 | 个人密码式分类难以协作与传承 |
| 论点、故事、证据同时存在 | 强论点可能诱发选择性取证 |
| 标题和讽刺提升传播率 | 敌我框架压缩复杂性 |
| 日定额支撑长期高产 | 复核、休息和改稿可能被挤压 |
| 跨书、刊、电视、演讲复用 | 同一故事会重复，作品边界与独立字数难审计 |
| 亲自写稿维持声音统一 | 单点依赖强，晚年体力成为瓶颈 |
